# Pico Git Tracker

A tool I made to track my Git projects on my Pico, since I had no better use for it.

## How to use

### JB IDEs:

Go into Settings and search for "Always show full paths in window header"

### Notepad++:

Works out of the box

### Anything else:

IDFK, as long as the full absolute file path is in the window title, it should work
